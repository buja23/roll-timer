# Fonte do temporizador

- Roboto Condensed, eixo `wght` 700 (Bold), arquivo variável original.
- Origem: https://github.com/google/fonts/tree/main/ofl/robotocondensed
- Licença: SIL Open Font License 1.1, texto integral em `OFL.txt` e também incorporado no APK em `assets/licenses/RobotoCondensed-OFL.txt`.
- Incorporada pelo plugin `expo-font`, família Android `RollTimerClock`, peso 700. Não requer internet durante o uso.
- Proporções naturais, numerais tabulares; não há escalas por eixo ou transformação do texto.

Barlow Condensed Bold também foi avaliada, incluindo `tabular-nums`. DIN Condensed foi consultada, mas não há licença de incorporação adquirida neste projeto; seu arquivo não é distribuído. Comparação e detalhes em `docs/V1.1.0.md`.
