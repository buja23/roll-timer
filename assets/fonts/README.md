# Fonte do temporizador

- Bebas Neue Regular, peso 400.
- Origem: https://github.com/google/fonts/tree/main/ofl/bebasneue
- Projeto: https://github.com/dharmatype/Bebas-Neue
- Licença: SIL Open Font License 1.1, texto integral em `OFL.txt`.
- Arquivo TTF original, sem modificações. Seus metadados também contêm atribuição e identificação da licença.
- Incorporada pelo plugin `expo-font`, família Android `RollTimerClock`; não requer internet durante o uso.

Anton foi avaliada, mas não é distribuída pelo aplicativo. A comparação e o dimensionamento estão documentados em `docs/REDESIGN.md`.
